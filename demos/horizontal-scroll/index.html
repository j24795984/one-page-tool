HORIZONTAL SCROLL
CSS Sticky / GSAP / Lenis

Horizontal Scroll

將垂直捲動進度映射為作品列表的橫向位移。桌面版以 CSS Sticky 固定展示舞台，由 GSAP ScrollTrigger 控制水平移動，並使用 Lenis 平滑原生捲動。

STEP 01 / CSS

建立 Sticky 舞台

外層保留垂直捲動高度，展示舞台使用 position: sticky 固定在視窗頂端。

STEP 02 / JavaScript

計算水平距離

以列表總寬度減去舞台寬度，取得水平移動距離並建立對等的垂直區間。

STEP 03 / GSAP

映射捲動進度

ScrollTrigger 讀取垂直捲動進度，將作品列表同步轉換為水平 translateX。

STEP 04 / Lenis

平滑捲動更新

Lenis 與 GSAP ticker、ScrollTrigger 同步，降低滾輪輸入造成的跳躍感。

流程完成

CSS Sticky / GSAP ScrollTrigger / Lenis

此效果為電腦版限定
