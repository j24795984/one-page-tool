01 / Subgrid

Subgrid 軌道繼承

當巢狀結構中的元素需要對齊外層網格時，可使用 subgrid 繼承父層軌道。

150px / 1fr / 1fr 軌道繼承

父層軌道：150px / 1fr / 1fr
標籤
輸入區域
.parent {
  display: grid;
  grid-template-columns: 150px 1fr 1fr;
}

.child-group {
  display: grid;
  grid-column: 1 / -1;
  grid-template-columns: subgrid;
}

02 / Card Alignment

Subgrid 卡片對齊

卡片跨越父容器定義的四個橫列，並使用 Subgrid 繼承列高。內容長度不同時，同列元素仍會對齊。

  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: auto auto auto auto;

  grid-row: span 4;
  grid-template-rows: subgrid;
