UI PATTERN

Horizontal Scroll

將頁面的垂直捲動進度映射到橫向內容位移，搭配 Sticky 舞台與平滑捲動形成連續瀏覽體驗。此範例以桌面寬度為主要展示情境。

效果說明

使用者仍以一般方式向下捲動，但進入展示區後，固定在視窗中的作品列會由右向左移動。當最後一張內容進入畫面，頁面才恢復垂直捲動並前往下一個段落。

適用情境

適合作品集、品牌歷程、產品系列與時間軸內容。建議用於桌面版，並為手機提供一般直向列表，避免狹窄畫面中的橫向內容過度壓縮。

引入方式

沿用獨立展示的 section、stage 與 list 三層結構，引入 horizontal-scroll.css、lenis/dist/lenis.css，並載入 GSAP、ScrollTrigger 與 Lenis。此展示在寬度大於 600px 且未啟用減少動態時執行。

  1. 以外層 section 提供足夠的垂直捲動距離，內層 stage 使用 position: sticky 固定在視窗頂端。
  2. 讀取橫向列表的 scrollWidth，再減去 stage 可視寬度，取得內容實際需要水平移動的總距離。
  3. 將計算結果同步寫入外層高度，確保垂直捲動距離與橫向移動距離一致。
  4. 建立 ScrollTrigger，把 section 的捲動進度映射到列表的 translateX，並使用 scrub 讓位移跟隨滾輪進度。
  5. Lenis 負責平滑捲動輸入，並與 GSAP ticker 及 ScrollTrigger 更新週期同步；視窗縮放時重新測量全部距離。

控制項目

.js-horizontal-section / stage / list
分別對應捲動區間、固定舞台與橫向列表；這三個元素決定移動範圍。
scrub
目前為 true，讓水平位移與捲動進度同步。
--horizontal-scroll-distance
程式以列表總寬度減去舞台寬度自動計算，視窗尺寸改變時重新測量。

使用技術

CSS Sticky · GSAP · ScrollTrigger · Lenis
