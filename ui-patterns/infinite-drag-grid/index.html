UI PATTERN

Infinite Drag Grid

利用座標循環與拖曳慣性，讓卡片網格在各方向持續延伸。適合作品牆、靈感圖庫與需要自由探索感的視覺索引。

效果說明

使用者可以往任意方向拖曳整片卡片牆，放手後會依拖曳速度繼續滑行。卡片離開一側邊界後會從另一側重新出現，因此視覺上沒有明確的起點與終點。

適用情境

適合作品探索、圖片靈感牆、品牌案例索引或藝術專案。內容需要以視覺探索為主，且不要求固定閱讀順序。

引入方式

建立 #viewport 與其內的 #grid-container，引入 infinite-drag-grid.css，載入 GSAP 並註冊 Draggable、InertiaPlugin。使用獨立展示中的初始化與 render 流程建立循環網格。

  1. 根據視窗、卡片尺寸與間距計算需要生成的欄數及列數，並在畫面外額外建立緩衝卡片。
  2. 記錄每張卡片的初始座標，使用 gsap.utils.wrap 建立 X、Y 軸的循環範圍。
  3. Draggable 只移動承載網格的容器，拖曳更新時再將容器位移加回每張卡片的初始座標。
  4. 座標超出循環範圍時由 wrap 換算到另一側，並透過 quickSetter 直接更新 transform，降低大量卡片重繪的成本。
  5. InertiaPlugin 處理放手後的慣性；視窗尺寸改變時重新建立網格與循環邊界。

控制項目

cardW / cardH / gap
JavaScript 預設為 320 / 220 / 24px；修改時需同步 CSS 的 --card-w、--card-h、--gap。
inertia
目前為 true，放手後依拖曳速度繼續滑行，需要 InertiaPlugin。
background-image
替換卡片圖片來源；實際專案可改用自己的圖片與標題資料。

使用技術

GSAP Draggable · InertiaPlugin · gsap.utils.wrap · quickSetter
