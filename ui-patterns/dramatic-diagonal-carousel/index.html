UI PATTERN

Dramatic Diagonal Carousel

以斜切遮罩建立具有編輯感的輪播構圖，並用垂直時間軸呈現各張內容的位置。適合攝影、建築或品牌作品集等需要強烈視覺節奏的全頁展示。

效果說明

畫面以大型斜切影像作為視覺核心，切換時圖片、遮罩與文字依序移動，右側時間點同步標示目前內容。使用者可以點擊時間點或操作輪播，在不同作品之間建立具有方向感的過場。

適用情境

適合攝影集、建築案例、品牌形象與活動主視覺。當內容數量不多，但每一筆都需要大幅影像與強烈敘事感時特別合適。

引入方式

沿用獨立展示中的 data-diagonal-carousel、data-slide 與 data-go-to 結構，引入 dramatic-diagonal-carousel.css；待 DOM 建立後載入 dramaticDiagonalCarousel.js。此實作不需要外部套件。

  1. 先建立重疊的 slide 結構，將每張圖片放入斜切遮罩中，並讓非目前項目保持在舞台外或不可見狀態。
  2. 依目前索引計算前一張與下一張內容，更新 slide、時間點及輔助文字的 active 狀態。
  3. 更新 slide 的 data-state，由 CSS Transition 處理位移、縮放與透明度；圖片以反向旋轉補償斜角構圖。
  4. 點擊右側時間點時切換到指定索引；鍵盤與滑動操作則依方向前進或返回一張。
  5. 動畫完成後清除暫時狀態並解除操作鎖定，避免快速連點造成多組時間軸互相覆蓋。

控制項目

data-go-to
指定要切換的 slide 索引，從 0 開始；時間點與 slide 順序需一致。
--diagonal-duration
CSS 位移時間，預設 1100ms；變更時須同步調整 goTo() 中的操作鎖定時間。
--diagonal-ease
CSS 位移緩動曲線；使用左右方向鍵或橫向滑動超過 40px 可切換。

使用技術

CSS Transform · CSS Transition · 原生 JavaScript · Keyboard Control
