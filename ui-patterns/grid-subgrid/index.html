UI PATTERN

Subgrid Alignment

示範巢狀元素如何繼承父層 Grid 軌道，以及不同內容長度的卡片如何共用列高，維持圖片、標題、內容與操作按鈕的一致對齊。

效果說明

多張卡片即使標題與內文長度不同，圖片、標題、說明及底部按鈕仍會落在相同水平線。巢狀表單或內容群組也能直接沿用外層欄線，不必重複宣告每一欄寬度。

適用情境

適合方案比較、商品卡片、文章列表、規格表與需要跨層級對齊的表單。它解決的是內容結構不同、但視覺基準必須一致的版面問題。

引入方式

使用 CSS Grid 建立父層共用軌道，讓子群組或卡片以 subgrid 繼承。獨立展示內含軌道繼承與卡片對齊的 HTML、CSS 範例，不需要 JavaScript 套件。

  1. 先在父層定義共用的欄或列軌道，讓所有需要互相對齊的項目位於同一個 Grid 格線系統。
  2. 巢狀群組使用 grid-template-columns: subgrid，並跨越父層指定欄位，直接繼承父層欄寬與格線。
  3. 卡片列表在父層建立圖片、標題、內容與操作區四列，每張卡片跨越四列並把 grid-template-rows 設為 subgrid。
  4. 瀏覽器會以同一列中最高的內容決定列高，因此其他卡片的後續區塊自然維持一致對齊。
  5. 在窄螢幕切換欄數或改為單欄排列，保留內容順序，同時避免固定欄寬造成水平溢出。

控制項目

grid-template-columns
決定父層欄數與欄寬；窄螢幕應改為較少欄數。
grid-row: span 4
讓卡片跨越圖片、標題、內文與按鈕四列；結構增減時需同步調整。
grid-template-rows: subgrid
讓同一排卡片共用列高，使內文長短不同時仍能對齊。
