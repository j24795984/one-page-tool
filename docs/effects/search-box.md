# 搜尋框

動作參考 yui540 motions/45、motions/62；本站以 CSS Keyframes 與原生事件實作，不使用 React。

- 展開搜尋框：小輸入入口擴大並回彈，右側搜尋按鈕進場。
- 放大鏡搜尋框：圓形入口拉伸成膠囊輸入框，握柄收起；內框圓角配合 5px 外框，略覆蓋 1px 接縫避免反鋸齒白線。
- 開關使用同一組 CSS Keyframes；原生 Animation API 控制正／負播放速度，收合反向經過回彈影格。快速切換從當前進度反轉，收合完成才隱藏輸入區，不瞬間消失。
- 切換前先暫停、保存 currentTime，同步設定 playbackRate 並還原進度，再變更焦點。不可用非同步方向更新後立即 play，也不可讓 focusin 接管回呼在方向設定前恢復播放。驗收需包含模擬接手後連續四輪開關的中間影格。
- 兩者皆點擊展開、點擊外部收合；內部點擊不收合，保留輸入文字。Esc 收合並恢復入口焦點。Enter／Space 可啟動入口。
- 使用真實 input；真人展開時聚焦，列表模擬不改焦點。搜尋提交僅示範，阻止預設導航，不串接搜尋服務。
- 類型：表單、按鈕；觸發方式：點擊；效果：展開、回彈；技術：CSS Keyframes。原生 JS 管理狀態，GSAP 僅用於共用假游標，不列為效果動畫技術。
- 列表共用搜尋元件及既有控制權管理器，模擬點擊入口與外部，不輸入文字；真人接管後停止示範。動態偏好與卸載依共用規範。
- 詳細頁提供 HTML／CSS／JS 範例與 JS 下載；無參數編輯面板。
