# 按鈕與 Dock 的效果規格

範圍：各效果獨有的外觀及動作。共用 [設計規範](../design-guidelines.md) 與 [預覽／控制權](../preview-interaction.md)；分類來源為 `src/data/button-effects.js`，列表與詳細頁重用 ButtonEffect、效果引擎及樣式。

## 095 磁吸按鈕

- 按鈕與中間文字各自跟隨游標；本體限制水平 ±12px、垂直 ±8px，文字額外跟隨本體位移 40%。
- 離開後兩者彈回；假游標靠近、區域內移動再離開。速度以容易辨認的小幅動作呈現。

## 103 游標擴散填滿

- 圓形底色以游標進入／離開位置為原點，直徑覆蓋最遠角落；鍵盤從中央觸發。
- 擴散／收回 0.55 秒，cubic-bezier(0.6,0,0.2,1)；文字轉色 0.45 秒。
- 模擬從左、上、右、下依序進入並向對側收回，填滿停留 0.3 秒。

## 110 旋轉光邊

- 彩色光邊例外：#FF6B4A → #7C5CFF → #00C8FF → #FF6B4A，搭配柔和彩色光暈。
- 按鈕底色與文字使用本站樣式；列表與內頁一致，持續旋轉且不使用假游標。

## 166 Dock 放大選單

- 七個 SVG 圖示依游標距離漸進放大，最大 1.7 倍，鄰項向兩側讓位。
- 底部對齊向上放大；背景高度依未 hover 的圖示尺寸加上下各 10px 留白及 2px 邊框計算，不預留放大後的高度。hover 時維持此高度，圖示可向上超出背景，僅寬度隨內容展開。
- 本站藍灰、低飽和綠、暖灰配色；Tab 聚焦放大對應項目，觸控點選聚焦。示範不導向其他頁面。
- 假游標左右掃過再返回。驗收須量測放大前後底座高度一致，並確認窄螢幕無溢出。

## 234 按鈕漣漪

- 從實際點擊位置擴散並淡出；Enter／Space 從中央觸發，可連續操作。
- 模擬點選不同位置，沿用同一點擊效果。

## 236 長按確認

- 連續按住 1.2 秒才完成；提早放開、移出、取消指標、失焦、背景或 Esc 均取消，支援滑鼠、觸控及 Enter／Space。
- 真人完成後展示確認結果、呼叫 onConfirm 並送出 confirmed；本網站示範不執行資料異動。
- 假游標先短按取消，再完整按住確認；業務事件隔離依共用控制權規範。

## 237 箭頭接力

右側箭頭滑出、左側新箭頭滑入、文字讓位；hover／鍵盤焦點啟動，離開反向還原。模擬移入、停留、離開。

## 287 社群圖示填滿

- 底色由下向上填入，圖示交替並輕微上浮，使用 inline SVG。
- 模擬 Instagram → Threads → Email → Link；一次一個，完成填滿、停留及反向退出後才輪到下一個。
- 每段停留依共用停頓上限配置，不要求與其他按鈕使用相同秒數；此規則取代早期統一端點 0.3 秒的描述。
