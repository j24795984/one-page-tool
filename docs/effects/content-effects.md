### 066 Odometer 模式

- 與數字揭示共用 Number Scroll 項目及詳細頁，以版本按鈕切換；不新增重複列表卡片。
- 數字揭示保留原本整圈滾動；Odometer 不增加額外圈數，未改變的位數保持靜止，增減時使用對應方向。
- createOdometer 保存前次目標值，提供 update(value) 與 destroy()；快速更新取消前次動畫並從前次目標繼續，沒有內建示範計時器。
- 詳細頁示範由 $12,480 開始，每秒加 1；切換模式、背景分頁、減少動態與卸載時清理計時器。列表維持預設的數字揭示。

## 065 拉霸 Slot Text

- 三格「大吉利」，隨機字池含中文字、符號及數字；本站藍灰文字／淺色窗格，上下有內陰影。
- 快速向上捲動，由左至右減速停下並略微回彈；第一格約 2.4 秒，後續每格延後 0.18 秒。
- 列表及詳細頁共用 SlotText；詳細頁初始化播放一次，可手動重播。列表以 0.9 倍速正反向循環，時間軸端點停留 0.3 秒（實際約 0.33 秒）。
- 效果模組只提供單次暫停時間軸與 destroy；循環、可見性及減少動態由展示元件處理。減少動態直接呈現結果。
- 類型為文字、觸發方式為自動播放，使用 GSAP；詳細頁提供 JS 下載及完整 CSS 引入範例。

## 250 水滴單選 Liquid Radio

- 圓點拉長成水滴、移到新選項並彈回圓形，沿用本站暖灰／藍灰。
- 選項不加外框及選取底色；只留圓形標記與文字。鍵盤焦點環限於標記。
- 選項中心距離 44px、標記與文字相隔 12px，列間不額外加留白；整組按實際內容寬度水平、垂直置中。
- 使用原生 radio，支援點擊、Tab、方向鍵；快速切換中斷前段動畫。
- 列表與內頁共用 LiquidRadio 與樣式；假游標依 1→2→3→2→1 點選往返，每次選取後停留 0.8 秒。
