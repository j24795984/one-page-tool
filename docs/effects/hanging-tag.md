# 吊牌擺動 Hanging Tag

動作參考：https://yui540.com/motions/25 的「カランカラン」。本站使用獨立 GSAP 模組與 Vue 展示層，不使用 React 或參考站素材。

- 類型：卡片；觸發方式：自動播放；效果：擺動；技術：GSAP。字母是吊牌內容，不另列文字類型。
- 水平位移、垂直位移與繞孔洞旋轉分為三層；CSS 繪製吊牌、吊繩與孔洞，使用本站主色。
- 入場與衰減擺動 1.1 秒，停留 0.45 秒，向下蓄力 0.25 秒，上收 0.5 秒。單輪 2.3 秒。
- 播放例外：列表與內頁同速，採完整入場／退場循環，不使用 yoyo。吊牌完全離開展示區時切換 A–D，避免可見跳接；不額外增加循環空檔。
- 模組只建立單次暫停時間軸；Vue 展示層管理循環、換字、背景暫停與 running。列表沿用可視區掛載，詳細頁提供重播。
- 減少動態時停在 rest 標籤，顯示完整靜態吊牌；卸載還原樣式並清除時間軸、媒體查詢與可見性監聽。
- 說明提供獨立 JS 下載及 HTML／CSS／ESM 單次播放範例；不提供參數編輯面板。
