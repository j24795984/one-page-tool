# 規範入口與工作流

正式規範整理日期：2026-10-29。先依任務選文件，讀取範圍以本次會修改或驗收的行為為準。

## 按任務讀取

| 任務 | 必讀文件 | 追加條件 |
| --- | --- | --- |
| 調整顏色、字級、間距或響應式外觀 | [設計規範](design-guidelines.md) | 改頁面結構時加讀頁面規格 |
| 列表、搜尋、篩選或詳細頁介面 | [頁面規格](page-spec.md) | 改分類／網址加讀內容契約；改外觀加讀設計規範 |
| 新增項目、分類、資料欄位或名稱 | [內容用語](../CONTEXT.md)、[內容契約](content-contract.md) | 新增效果走下方流程 |
| 動畫、列表預覽、假游標、控制權或資源清理 | [預覽與互動](preview-interaction.md) | 讀取該效果的規格，外觀變更加讀設計規範 |
| 個別效果調整 | [效果索引](effects/README.md) 中對應文件／段落 | 同時讀取本次涉及的共用規範 |
| 維護截圖、影片或素材來源 | [素材紀錄](preview-assets.md) | 改資料欄位加讀內容契約 |
| 回查已完成階段或既有驗證 | [階段紀錄](archive/2026-10-29-preview.md) | 歷史紀錄不作目前行為依據 |
| 小工具、首頁、字體庫 | 依任務讀設計規範／內容用語 | UI 庫專屬規則只在共用元件受影響時讀取 |
| 只改文件 | 待改文件及其直接引用的規範 | 檢查入口、責任歸屬與連結；不要求建置網站 |

跨多種任務時取所需文件的聯集。小幅修改可只讀效果索引指定段落；修改共用規則則讀完整的責任文件。

## 新增效果流程

1. 讀設計規範、內容契約、預覽與互動；讀頁面規格中將接入的列表／詳細頁段落。
2. 參考效果需實際確認；記錄使用者指定的差異。以本站視覺規範及明確例外決定 UI。
3. 效果本體與列表共用素材、結構及動作；接入獨立示範腳本與控制權管理，不把模擬邏輯放入效果本體。
4. 新增分類資料、列表展示、詳細頁、引入說明與可下載來源；更新效果索引及該效果規格。
5. 依責任文件驗收受影響行為，記錄已測與未測項目。只執行與本次變更相關的驗證。

## 文件維護原則

- 每條正式規則只有一個責任文件；其他文件以連結引用。
- 使用者新指示優先。修改決策時更新原段落，避免在檔尾再附一份互相矛盾的版本。
- 效果數量、完整分類及程式檔位置以目前資料來源為準，不在多份規範維護副本。
- 正式規範定義預期行為；程式只用來確認實作。差異須明列，不能以舊程式覆蓋已確認決策。
- 既有驗證、參考來源與待辦放在紀錄；紀錄中的「通過」不代表後續修改自動通過。
- 新增文件時補上本入口或效果索引的讀取條件；移動文件時保留舊入口或修正引用。
