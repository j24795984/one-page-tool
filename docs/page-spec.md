# UI 庫頁面規格

範圍：列表與詳細頁的結構、導覽及操作介面。配色見 [設計規範](design-guidelines.md)，分類／網址見 [內容契約](content-contract.md)，展示動作見 [預覽與互動](preview-interaction.md)。

## 列表與篩選

- 篩選區在上、卡片使用下方完整寬度；順序為類型 → 觸發方式 → 風格 → 技術。
- 分類以可複選按鈕呈現，點選即套用，再次點選取消。
- 關鍵字列位於分類下方，「搜尋」「清除」靠右；窄螢幕可換行靠右。按搜尋或 Enter 才提交文字。
- 清除同時重設分類、已套用關鍵字、未提交輸入及網址。
- 篩選框外直接顯示卡片或無結果提示，不加已選條件標籤列或「顯示 N 個項目」。

## 卡片

依序顯示：

1. 16:10 效果展示；不加「自動示範／查看詳細體驗」提示列。文件標示在預覽內，錯誤提示只在載入失敗時出現。
2. 跨預覽與文字交界的類型標籤，外觀依設計規範。
3. 名稱連結。
4. 一句簡述，最多兩行。
5. 效果與技術標籤同區，全部顯示並可換行。

- 僅名稱連結進入詳細頁；整卡不包連結，卡片底部不另設「查看詳細」。
- 預覽的輸入權限依預覽與互動規範；捲輪應繼續捲動列表。
- 寬桌面四欄、一般桌面三欄、平板兩欄、手機一欄；斷點以可讀性及無水平溢出驗證。
- `/ui/`、`/ui-showcase/`、`/js-effects/` 共用列表；`/ui-patterns/` 使用相同預覽元件呈現版面子集合。

## 詳細頁

- 桌面左側說明、右側大預覽，左右各自捲動。
- 手機固定預覽視窗；工具列提供帶向下箭頭的「效果說明」，預設收合。展開後覆蓋預覽，只允許說明面板捲動，背景預覽不可操作；再次點選或 Esc 收合並恢復操作。
- 說明包含引入方式、控制項目文件、程式碼範例及目前初始化。複製按鈕需回報結果；下載名稱依實際內容標示「JS 下載」或「HTML 範例下載」。
- UI 效果頁不提供可編輯數值的參數面板；本規則不適用小工具介面。
- 必要重播／版本切換放在預覽上方，個別內容見效果規格。
- 完整頁面範例可於詳細頁以 iframe 載入 `/demos/[slug]/`，提供獨立展示入口；原 `/ui-patterns/[slug]/` 詳細網址保留。

## 頁面驗收

驗證篩選、搜尋、清除、網址還原、名稱導覽、複製／下載及本次涉及的手機說明切換；鍵盤可到達各操作，預覽不得吞掉列表捲輪。
