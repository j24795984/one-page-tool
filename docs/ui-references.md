# UI 參考網站

## 責任範圍

外部 UI 展示網站的收錄、資料與查詢規則。此處收藏網站；可直接引入本站專案的效果仍歸 UI 庫管理。

## 資料與分類

- 唯一資料來源：`src/data/ui-references.js`。每筆包含穩定 id、名稱、HTTPS 網址、網域、說明、網站預覽圖片、風格、特色及搜尋別名。
- 暫不提供類型。特色描述網站展示與瀏覽方式，例如動態示範、分類篩選；AI 提示詞複製只寫入說明，不列為特色標籤。
- 風格描述整站展示傾向。目前使用「俏皮」及「多元」；「可愛」作俏皮的搜尋別名。涵蓋多種風格的網站使用「多元」，不強迫套用 UI 庫單一效果的風格分類。
- 收錄應依實際頁面或使用者確認的資訊，不將沒有提供的程式碼、套件或下載能力列為特色。

## 頁面與查詢

- 路由 `/ui-references/`，首頁及主導覽提供入口。
- 篩選順序為風格、特色；各組可多選，組內 OR、組間 AND，未選擇不限制。
- 關鍵字以 Enter 或搜尋按鈕提交，搜尋名稱、網域、說明、風格、特色與別名，不分英文大小寫。
- URL 保存已提交關鍵字與篩選，可重載及分享；清除同步清空輸入、條件與相關網址參數。空結果提供清除操作。
- 卡片呈現實際網站縮圖、網站名稱、網域、說明與標籤，不提供底部小字。風格與特色標籤混排，使用相同低對比樣式與緊密間距；標題連結另開外部網站，提供新分頁提示及 `noopener noreferrer`。
- 圖片使用本地靜態網站截圖，提供替代文字、固定 16:9 比例及延遲載入；來源為各筆外連網站。不嵌入外站自動執行的頁面。桌面每排一張橫向卡片，左側圖片最多佔卡片 35% 寬，右側文字區填滿其餘寬度並讓標籤靠下；手機改為上圖下文，依共用設計規範呈現。

## 驗收

檢查分類組合、說明與別名查詢、空結果與清除、URL 還原、外連屬性，以及窄螢幕無水平溢出。新增資料無須讀取動畫控制規範。
