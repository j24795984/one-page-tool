# 共用視覺規範

範圍：顏色、字體、標籤及外觀驗收。頁面行為見 [頁面規格](page-spec.md)，動畫與控制權見 [預覽與互動](preview-interaction.md)，個別效果例外見 [效果索引](effects/README.md)。

## 視覺方向

- 使用者為站主本人；以查找、觀看及取用資源為核心。清楚、簡潔、平衡資訊密度。
- 暖灰頁面、白色卡片與低飽和藍色。縮短頁首留白，優先讓篩選與第一排內容出現在首屏。
- 色票為使用者定案；未確認的外部設計圖片不構成規範。

| 角色 | 色碼 |
| --- | --- |
| 頁面底色 | #F7F7F4 |
| 卡片／輸入框 | #FFFFFF |
| 主要文字 | #252A30 |
| 次要文字 | #626971 |
| 主色 | #496783 |
| 選取底色 | #E8EEF3 |
| 邊框 | #DEDFDA |

- Inter 搭配系統中文字體；內文 16px、輔助 14px、頁面標題 28–32px。
- 卡片圓角 12px，輸入框／按鈕圓角 8px；效果另有明確規格時依該效果。
- 列表卡片的 hover 回饋採顏色及邊框，不上浮；此規則不限制展示內容本身的動作。

## 卡片標籤

- 類型：14px 白字、#496783 實色底，跨預覽與文字區交界置中，左側與標題對齊；多個類型以「·」分隔。
- 效果：#496783 文字／#E8EEF3 底色。
- 技術：#466453 文字／#EAF0EB 底色。
- 效果與技術標籤皆為 14px、圓角 4px，同尺寸同間距，可換行；不添加箭頭。

## 外觀驗收

- 檢查文字對比、可見鍵盤焦點、長標題及窄螢幕溢出。
- 精確斷點、留白及焦點樣式可依實際內容決定；不得改變已確認的版面結構或互動。
- 首頁、小工具、字體庫可沿用此視覺規範；各自專屬資訊配置尚未定案。
