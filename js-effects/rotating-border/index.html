旋轉光邊按鈕

JS 下載 ↓

橘紅、紫與亮青色漸層沿按鈕邊框持續旋轉，帶出柔和光暈。

使用方式

進入畫面即自動旋轉，離屏與背景分頁暫停。

引入方式

HTML

<div class="button-effect-stage" data-button-effect="rotating-border">
<button type="button" class="motion-button"><span class="button-border-clip" aria-hidden="true"><span class="button-border-light"></span></span><span class="button-label">開始使用</span></button>
</div>

JavaScript / ESM

import { initButtonEffect } from './button-effects.js';
// 先安裝 gsap 並套用下方 CSS。
const effect = initButtonEffect({ root: document.querySelector('[data-button-effect="rotating-border"]') });
// 元件卸載時 effect.destroy();

控制項目

root / data-button-effect
傳入單一效果容器；data-button-effect 指定範例種類。多個實例各自初始化與清理。
running / controls
running 控制執行；controls 提供與原生事件共用的效果操作。自動示範由列表的獨立模擬器負責。
onConfirm
僅長按確認使用：連續按滿 1.2 秒後呼叫一次，同時送出 confirmed DOM 事件；本頁只展示確認結果。
動態與鍵盤
填色、箭頭及社群圖示支援鍵盤焦點；漣漪支援 Enter / Space。長按可持續按住 Enter / Space，放開、移出、失焦或 Esc 取消。減少動態偏好停用列表動畫與旋轉，互動直接呈現狀態；長按仍需完整等待。
