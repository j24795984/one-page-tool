JS Effect

Object Fade Active

當物件進入可視範圍時，以透明度與位移呈現進場效果；回捲離開觸發線後會重置，可重複觀看。

使用方式

在目標元素加入 data-object-fade，並透過屬性內容設定效果參數。

DOM 元素

<div data-object-fade>
  Effect content
</div>
fade
進場方向：up、down、left、right。
duration
動畫時間，單位為秒。
offset
初始位移距離，單位為 px。
start
元素頂端到達展示區百分比時觸發。
stagger / delay
同批項目的間隔與整批延遲秒數。
reset
開啟時回捲會重置並可再次播放；關閉時只觸發一次。

目前設定

data-object-fade="fade=up&duration=0.75&offset=56&start=84%&stagger=0.12&delay=0&ease=power2.out&reset=true"
