彈性拉伸 Elastic Wave Stretch

JS 下載 ↓

文字以底部為軸依序拉長、變窄再回彈，形成連續波浪。

使用方式

各字依序縱向拉長至 1.7 倍、橫向縮至 0.75 倍，彈性回到原位；最後一字使用主色強調。 引入 GSAP 與下方 CSS；效果本體不含列表循環模擬。

引入方式

HTML

<div class="text-motion text-motion--elastic-wave-stretch" style="height:500px;--motion-height:500px"><div class="text-motion__stage"><p data-effect class="text-motion__text">彈性波浪</p></div></div>

JavaScript / ESM

import { createEffect } from './elastic-wave-stretch.js';
const effect = createEffect({ element: document.querySelector('[data-effect]') });
if (matchMedia('(prefers-reduced-motion: reduce)').matches) effect.timeline.pause().progress(0);
else effect.timeline.play();
// 卸載時：effect.destroy();

控制項目

element
效果元素；文字內容取自元素本身。斜線反轉需要內層 data-invert。
timeline
GSAP 時間軸，可播放、暫停、反向或設定 progress(0–1)。
destroy()
移除時間軸、監聽器與觀察器，還原原始內容。
