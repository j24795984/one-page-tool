JS Effect

Text Fade

將文字拆分為單字元，在進入可視範圍時依序淡入，適合標題、引言與短篇文案。

使用方式

依效果在文字元素加入對應的 data attribute，再統一呼叫 initFadeText()。

DOM 元素

<h2 data-fade-text>Fade Up</h2>
<h2 data-fade-3dtext>Matrix 3D</h2>
<h2 data-fade-brtext data-fadeT-start="90">
  Preserve<br>Line Break
</h2>

JavaScript

initFadeText();
data-fadeT-start
僅供 data-fade-brtext 使用，設定觸發位置，預設為 90。

目前 DOM

<h2 data-fade-text>Text reveal effect</h2>
