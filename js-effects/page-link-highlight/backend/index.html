Server-rendered HTML

後端已知道目前命中的路由，不需要在瀏覽器重新解析網址。以 route name 或 menu section 作為唯一狀態來源，再由模板輸出 class 與 aria-current。

狀態來源
Slim RouteContext、route name 與 menu section
更新時機
每一次伺服器 request render
建議定位
路由決定狀態，模板輸出語意，CSS 負責視覺
  • 所有需要判斷的 Slim route 都應設定名稱。
  • 詳細頁使用相同 section，避免依動態 slug 判斷。
  • 目前頁使用 aria-current；父層分類可使用 is-ancestor。

範例建構程式碼

架構示意，不執行效果
命名路由與 SectionPHP
$app->get('/products', ProductController::class . ':index')
    ->setName('products.index');

$app->get('/products/{slug}', ProductController::class . ':detail')
    ->setName('products.detail');

$currentSection = str_starts_with($currentRoute, 'products.')
    ? 'products'
    : null;
模板輸出Twig
<a
  href="{{ url_for('products.index') }}"
  class="{{ currentSection == 'products' ? 'active' : '' }}"
  {% if currentRoute == 'products.index' %}aria-current="page"{% endif %}
>
  Products
</a>
