Shopline/第三方平台注入方式

Injected enhancement

在不能修改後端、路由與 HTML 架構，只能注入 JavaScript/CSS 的前提下，目前以 pageLinkFocus.js 判斷網址並修改既有 Top Menu class 的方向是合理的。

狀態來源
window.location 與既有 Top Menu 連結
更新時機
頁面載入；平台使用 AJAX 換頁時需再次執行
建議定位
保留 pageLinkFocus.js 作為第三方平台專用 fallback
  • Selector 應限定在 Top Menu，避免同時修改 Footer 或內容連結。
  • 完全相同路徑優先；否則選擇最長且有效的父路徑。
  • 特殊網址映射應集中設定，不寫死在共用比對流程。
