圓餅圖分段

JS 下載 ↓

四段環圈依序描繪，對應圖例從右側滑入。中央保留總比例，適合流量來源與占比統計。

使用方式

參考 Motion Library 的 Donut Chart Segments，使用 SVG 與 GSAP 重新實作。進入可視區後播放一次，離開畫面或背景分頁暫停；可使用上方按鈕重播。

JavaScript / ESM

import { initDonutChart } from './donut-chart.js';
// 模組使用 gsap，請先 npm install gsap。
const chart = initDonutChart({ root: document.querySelector('.chart') });
// chart.restart();
// 離開頁面時 chart.destroy();

控制項目

root
包含 SVG 圓環及 data-legend 圖例的容器；各圓環使用 data-percent 設定比例。
分段與間隙
預設 42%、28%、18%、12%；各段保留圓周 1.2% 的間隙，從十二點方向開始順時針描繪。
播放節奏
每段 0.6 秒，圖例同時以 0.4 秒滑入。列表以 1.5 倍速正向／反向播放，端點停留 0.2 秒（0.3 秒經倍速換算）。
preview / running
列表模式由既有可見性排程控制播放；不提供操作，不建立 iframe。
restart / destroy
重新播放；或解除觀察器、事件與動畫並還原 SVG。減少動態偏好顯示完整靜態圖表。
