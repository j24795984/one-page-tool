UI Effect

吊牌擺動 Hanging Tag

JS 下載 ↓

吊牌落下後左右擺動，停穩再收回，依序展示字母。

使用方式

引入 GSAP 與下方 CSS。模組提供單次入場與收回；本站由 Vue 展示層管理 A–D 換字、循環及背景暫停，不使用 React。

引入方式

HTML

<div class="hanging-tag" style="height:400px"><div data-sway class="hanging-tag__sway"><div data-lift class="hanging-tag__lift"><div data-tag class="hanging-tag__card">A</div></div></div></div>

JavaScript / ESM

import { createEffect } from './hanging-tag.js';
const root = document.querySelector('.hanging-tag');
const effect = createEffect({ element: root });
if (matchMedia('(prefers-reduced-motion: reduce)').matches) effect.timeline.pause('rest');
else effect.timeline.play();
// 卸載時呼叫 effect.destroy();

CSS

.hanging-tag__sway { width:clamp(40px,20cqh,100px); }

.hanging-tag__lift::before { content:''; position:absolute; width:3px; height:100cqh; bottom:calc(100% - 12px); left:50%; transform:translateX(-50%); background:#496783; border-radius:2px; }
.hanging-tag__card { position:relative; width:100%; aspect-ratio:20/26; display:grid; place-items:center; padding-top:15%; box-sizing:border-box; border-radius:8px; background:#496783; color:#fff; font:600 clamp(26px,12cqh,60px)/1 Inter,sans-serif; transform-origin:50% 12px; }
.hanging-tag__card::before { content:''; position:absolute; top:8px; left:50%; transform:translateX(-50%); width:8px; height:8px; border-radius:50%; background:#F7F7F4; }

控制項目

element
包含 data-sway、data-lift、data-tag 的展示根元素。
timeline
暫停的 GSAP 時間軸；play() 播放，pause() 暫停，pause("rest") 顯示停穩吊牌。
destroy()
清除時間軸並還原原始行內樣式。
