JS Effect

Custom Scrollbar

JS 下載 ↓

保留瀏覽器原生捲動行為，另外以可拖曳滑塊呈現目前閱讀位置。適合固定高度的內容面板、選單與彈出視窗。

使用方式

內容由原生 overflow 捲動；模組依 scrollTop 同步固定高度滑塊的位置，並提供滑鼠拖曳控制。

引入方式

DOM 結構

<div class="scroll-shell">
  <div id="article-scroll" class="scroll-container">
    <div class="scroll-content">...</div>
  </div>
  <div class="scroll-track">
    <div class="scroll-thumb"></div>
  </div>
</div>

JavaScript / ESM

import { initCustomScrollbar } from './custom-scrollbar.js';

const scrollbar = initCustomScrollbar({
  container: document.querySelector('.scroll-container'),
  track: document.querySelector('.scroll-track'),
  thumb: document.querySelector('.scroll-thumb')
});

// scrollbar.update();
// scrollbar.destroy();

控制項目

container
實際產生 scrollTop 的 overflow 容器。
track
自訂捲動軌道；沒有溢位內容時會自動隱藏。
thumb
固定高度的滑塊，支援滑鼠上下拖曳。

目前設定

initCustomScrollbar({ container, thumb, track });

操作方式

使用滾輪或觸控板捲動內容，也可以拖曳右側滑塊控制位置。

Reading Panel

A quieter way to navigate long content

捲動內容會同步右側滑塊；也可以按住滑塊上下拖曳。

01

原生捲動仍是核心

內容容器繼續使用瀏覽器的 scrollTop，因此滑鼠滾輪、觸控板、觸控滑動與程式控制都維持原生行為。自訂介面只負責把閱讀進度映射至滑塊。

02

滑塊同步閱讀位置

以目前 scrollTop 除以最大捲動距離，再映射至軌道可移動範圍，讓固定高度滑塊反映目前閱讀位置。

03

更新集中在動畫影格

高頻 scroll 事件只提出更新要求，真正的尺寸讀取與 transform 寫入會合併到下一個 requestAnimationFrame，降低重複版面計算。

04

容器尺寸變動時更新

ResizeObserver 監測捲動容器，面板高度或寬度改變時重新計算滑塊位置。

05

解除事件與還原狀態

destroy() 會移除捲動、滑鼠與尺寸監聽，並還原初始化前的行內樣式。
