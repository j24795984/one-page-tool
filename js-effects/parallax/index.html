JS Effect

Parallax

JS 下載 ↓

將元素綁定原生捲動位置，依元素速度與初始偏移產生垂直視差效果。

使用方式

在視差元素加入 luxy-el 類別與對應的 data attribute，再呼叫 parallax.init()。

引入方式

DOM 元素

<div class="luxy-el" data-speed-y="10" data-offset="-50">
  Parallax content
</div>

JavaScript / ESM

import { parallax } from './parallax.js';

parallax.init({
  targets: '.luxy-el',
  targetSpeed: 0.02,
  scrub: true
});

控制項目

data-speed-y
控制元素在 Y 軸上的移動速率。
data-offset
控制元素初始的 Y 軸偏移量。
targets
指定要套用效果的元素選擇器，預設為 .luxy-el。
targetSpeed
設定整體視差移動倍率，預設為 0.02。
scrub
設定效果是否跟隨捲動進度，預設為 true。
