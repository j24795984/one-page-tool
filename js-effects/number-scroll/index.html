JS Effect

Number Scroll

JS 下載 ↓

提供數字滾動揭示與 Odometer 計數器兩種模式；前者整圈揭示成果，後者只轉動改變的位數，適合持續更新的統計。

使用方式

引入 GSAP 與下方 CSS。initNumberScroll() 播放一次並回傳 cleanup；createOdometer() 保存目前數值，透過 update(value) 更新，卸載時呼叫 destroy()。示範計時器由頁面負責。

引入方式

DOM 元素

<span class="number-scroll" data-number-scroll></span>

JavaScript / ESM

import { initNumberScroll } from './number-scroll.js';

const cleanup = initNumberScroll({
  element: document.querySelector('[data-number-scroll]'),
  start: 12480,
  end: 128640,
  duration: 1.6
});

Odometer / 即時資料更新

import { createOdometer } from './number-scroll.js';
const counter = createOdometer({ element: document.querySelector('[data-number-scroll]'), start: 12480, duration: 0.65, prefix: '$' });
counter.update(12481);
// 下一次資料抵達時：counter.update(12500);
// 卸載時：counter.destroy();

控制項目

start / end
起始值與目標值；整數部分最多 9 位。
duration / ease
滾動秒數與 GSAP easing。
decimals
固定小數位數，範圍 0–3。
grouping
是否顯示千分位分隔符號。
prefix / suffix
固定顯示於數值前後的文字或符號。
mode / update(value)
mode: reveal 為整圈揭示，odometer 不加額外圈數，未變位數靜止。createOdometer.update(value) 依增減決定方向；快速連續更新會取消前次動畫，從上次目標值開始。
