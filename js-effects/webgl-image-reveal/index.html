JS Effect

WebGL Image Reveal

JS 下載 ↓

以 PixiJS 與 GSAP 製作可選的圖片揭露效果，包含交界像素延伸，以及水平切片搭配位移貼圖的扭曲轉場。

使用方式

準備一個承載 canvas 的容器，選擇 variant 並傳入圖片網址。Edge Stretch 使用單張圖片；Slice Displacement 使用多張圖片並在每次 play() 時切換到下一張。

引入方式

DOM 元素

<div id="webgl-image"></div>

JavaScript / ESM

import { initWebGLImageReveal } from './webgl-image-reveal.js';

const reveal = await initWebGLImageReveal({
  container: document.querySelector('#webgl-image'),
  variant: 'slice-displacement',
  imageUrls: [
    '/images/slide-1.jpg',
    '/images/slide-2.jpg',
    '/images/slide-3.jpg'
  ],
  slices: 10
});

reveal.play();
// reveal.reset();
// reveal.destroy();

控制項目

container
PixiJS canvas 的掛載容器。
variant
edge-stretch（預設）或 slice-displacement。
imageUrl
Edge Stretch 使用的單張圖片；跨網域圖片必須允許 CORS。
imageUrls
Slice Displacement 依序切換的圖片陣列。
slices
水平切片數量，預設為 10。
width / height
WebGL 畫布邏輯尺寸，預設為 800 × 500。
play / reset
執行目前效果，或回到初始狀態。
destroy
停止 Tween 並釋放 PixiJS、Texture 與 WebGL 資源。

目前初始化

await initWebGLImageReveal({ container, imageUrl: 'https://picsum.photos/id/1015/800/500' });

注意事項

  • 跨網域圖片必須提供允許 Canvas 使用的 CORS 回應標頭，否則 Texture 可能載入失敗。
  • Slice Displacement 會為每張圖片建立多個切片與濾鏡；圖片數量、解析度與 slices 越高，GPU 與記憶體負載越大。
  • 不同圖片比例會先以 cover 方式縮放，重要內容請避免過度靠近圖片邊緣。
  • 參考網站約每 7 秒自動輪播；此工具頁刻意保留手動播放，方便逐次檢視與重置效果。
  • 系統啟用 prefers-reduced-motion 時，轉場會直接完成，避免持續扭曲造成不適。
