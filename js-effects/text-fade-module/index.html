Text Fade Module

JS 下載 ↓

可獨立匯入的 GSAP 逐字顯示模組，以 data-text-fade 組合淡入、上移與模糊效果。

使用方式

在文字容器上設定 data-text-fade，匯入模組並傳入 GSAP 實例；匯入本身不會自動初始化。

引入方式

HTML

<h2 data-text-fade="timing(d:0.27;o:0.8;e:none) fade rise(y:9) blur(b:10)">效果展示</h2>

JavaScript / ESM

import { gsap } from 'gsap';
import { createTextFade } from './text-fade.mjs';

const effect = createTextFade(element, { gsap });
effect.timeline.play();
// 離開頁面時呼叫 effect.destroy();

控制項目

timing(d, o, s, e)
設定每字秒數、重疊比例或間隔秒數，以及 GSAP ease；s 優先於 o。
fade(from, to)
設定不透明度起點與終點。
rise(y)
設定逐字向上移動的起始距離，單位為 px。
blur(b)
設定起始模糊半徑，單位為 px。
