UI EFFECT

分類導覽滑動效果

HTML 範例下載 ↓

圓點指示器跟隨滑鼠移入、鍵盤焦點與選取項目移動；移出後回到目前選取項目。

使用方式

將分類按鈕放入 .category-nav，並使用原始 HTML 中的樣式與腳本控制指示器。

引入方式

HTML

<nav class="category-nav" aria-label="分類導覽">
  <span class="category-indicator" aria-hidden="true"></span>
  <ul class="category-list">…</ul>
</nav>

JavaScript

const target = hoveredLink || focusedLink || selected;
positionIndicator(target);

控制項目

--theme-base
指示器及分隔線的主題色。
aria-pressed
標示目前選取的分類；點擊時同步更新。
