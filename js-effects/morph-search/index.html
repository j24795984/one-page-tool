UI Effect

放大鏡搜尋框 Morph Search

JS 下載 ↓

點擊展開輸入，點擊外部收合，保留搜尋內容。

使用方式

CSS Keyframes 負責尺寸回彈與圖示動畫，原生 JS 管理點擊、焦點及 CSS 動畫反向播放。點擊展開、點擊外部或 Esc 收合；保留輸入文字。搜尋按鈕僅示範，不送出查詢。

引入方式

HTML

<div class="search-stage" style="height:400px"><form class="search-motion search-motion--morph" role="search"><button data-open type="button" aria-label="展開搜尋" aria-expanded="false"></button><div data-field inert aria-hidden="true"><input type="search" aria-label="搜尋關鍵字" placeholder="搜尋關鍵字"><button data-submit type="submit" aria-label="搜尋"><i class="search-glass" aria-hidden="true"></i></button></div></form><span data-outside aria-hidden="true"></span></div>

JavaScript / ESM

import { initSearchBox } from './search-box.js';
const effect = initSearchBox({ root: document.querySelector('.search-motion') });
// 卸載時：effect.destroy();

控制項目

root
搜尋表單根元素，含 data-open、data-field 與 input。
setRunning(boolean)
控制搜尋框及子元素動畫播放狀態。
destroy()
清除點擊、鍵盤、表單及背景監聽。
